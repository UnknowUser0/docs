Backend Golan Sertifikasi menyediakan REST API publik berversi untuk web dan Android. Semua klien terhubung melalui satu gateway.

## Base URL

| Lingkungan | URL |
| --- | --- |
| Web lokal | `http://localhost:18080/api/v1` |
| Android Emulator lokal | `http://10.0.2.2:18080/api/v1` |
| Production | `https://<domain-api-anda>/api/v1` |

## Alur utama

1. Tukarkan Google ID token dengan `POST /auth/google`.
2. Kirim access token sebagai `Authorization: Bearer <token>`.
3. Jika `onboarding_required: true`, selesaikan profil melalui `PUT /me/onboarding`.
4. Gunakan API katalog, pembelajaran, transaksi, dan notifikasi.

<Warning>
  Panggil hanya gateway publik. Jangan hubungkan aplikasi ke PostgreSQL, RabbitMQ, gRPC, ClamAV, atau port service internal. Secret Midtrans, S3, dan token antarlayanan hanya boleh berada di backend.
</Warning>

## Sumber kebenaran

OpenAPI menentukan schema dan security endpoint. Backend menentukan otorisasi, saldo, harga, pajak, diskon, refund, progress, dan sertifikat. Nilai uang berupa integer Rupiah; fitur finansial dapat mengembalikan `503` bila kebijakan belum diaktifkan.
